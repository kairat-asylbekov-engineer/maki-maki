# Maki Maki — демо-сайт доставки суши

Демо-версия главной страницы для суши-кафе «Maki Maki», свёрстанная по макету «Главная».

**Стек:** Next.js 16 (App Router) · TypeScript · Tailwind CSS v4 · lucide-react
**Шрифты:** Unbounded (заголовки) и Onest (текст) — те же, что в макете, подключены локально через `@fontsource`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
```

Продакшен-сборка:

```bash
npm run build
npm start
```

Деплой: проект готов к Vercel / Netlify без дополнительных настроек (страница полностью статическая).

## Что внутри

- Первый экран с шапкой, логотипом и четырьмя карточками категорий
- Преимущества, плитки категорий, «Популярное сегодня» (сначала скелетоны, как в макете, затем товары — имитация загрузки с API)
- Баннеры «Счастливый ролл дня» и «Акция для новых клиентов»
- «Почему выбирают нас», «О нас», «4 шага», отзывы, контакты и Telegram-канал
- Демо-корзина: добавление товаров, счётчик, плавающая кнопка, выезжающая панель, итог и «оформление» (сохраняется в localStorage)
- Адаптив: десктоп по макету (1080px — пиксель в пиксель по вертикали), планшет и мобильные

## Где менять контент

Все тексты, город, валюта, телефон, ссылки на соцсети, товары и отзывы — в одном файле:
`src/data/site.ts`

Изображения — `public/images/` (фото взяты из макета, логотип — `logo.webp`).

## Структура

```
src/
  app/            layout, page, глобальные стили и токены (globals.css)
  components/
    sections/     секции главной страницы
    cart/         провайдер корзины и выезжающая панель
    ui/           кнопки и иконки
  data/site.ts    моковые данные
```
